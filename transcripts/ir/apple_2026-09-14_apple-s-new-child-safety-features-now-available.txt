Apple’s new child safety features now available

Apple’s new tools help parents create safer digital experiences for their kids, including the ability to set Time Allowances across categories like Entertainment, Games, and Social Media, and easily adjust app and web access with a redesigned Screen Time.

Apple’s new suite of powerful, intuitive, and easy-to-use tools helps parents create safer digital experiences for their kids and is now available with the latest software updates to iOS 27, iPadOS 27, and macOS 27. These updates give parents more flexibility to manage the content their children see, who they can communicate with, and when they have access to apps.

These new features, previewed in June, build on Apple’s already industry-leading parental controls, and include:

A simpler setup experience with a recommended set of essential apps for new child accounts.

Ask to Browse, which allows parents to require approval before their kids access a new website in Safari.

Expanded Communication Safety protections that now block gore and violent content, in addition to nudity, in shared images and videos, including in live FaceTime calls.

Time Allowances, which give parents expert-informed, age-tailored guidance, as a helpful starting point, for managing time spent in app categories like Social Media, Entertainment, and Games.

A redesigned Screen Time that gives parents an at-a-glance view of usage and one-tap controls to adjust access in the moment.

These updates are informed by guidance from online safety and health experts, including the American Academy of Pediatrics, which Apple is working with to adapt its Family Media Plan into a guide parents can reference when using Apple products.

For parents and families looking for more information about how to help create safer, more enriching digital experiences for their kids, Apple has launched a dedicated website , which includes details on the latest tools and how to get started using them.

Availability

New features are available now with the Screen Time update in iOS 27, iPadOS 27, and macOS 27. All devices in a Family Sharing group must be updated to iOS 27, iPadOS 27, macOS 27, watchOS 27, and visionOS 27 to use the Screen Time update. Some features may not be available in all regions, all languages, or on all models. For more information about availability, visit apple.com .

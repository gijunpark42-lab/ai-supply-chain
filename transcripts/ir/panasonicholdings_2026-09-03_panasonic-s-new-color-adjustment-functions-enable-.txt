Development Background

Video productions using LED walls and live events featuring diverse lighting effects are expanding rapidly. However, in production environments, the types of light sources are increasing, making it difficult to reproduce intended colors and achieve natural-looking subjects. In addition, when highly saturated colors are used for corporate logos or sponsor colors displayed on LED walls, or for various stage effects, balancing the color reproduction between the on-stage subjects and LED wall footage can require considerable time and effort. To address these challenges, Panasonic has developed new functions that will make it easier for video creators to achieve their desired color expression.

Key Features

1. Color Temp. Blend Achieves Natural Color Reproduction Even in Multi-Light-Source Environments

It has become common for shoots to take place in environments where LED walls and stage lighting coexist. However, if each light source has a different color temperature, the color reproduction of people and other subjects can appear unnatural. Since conventional white balance settings can hold only one reference color temperature, users must choose between using the footage on the LED wall or the stage lighting as the reference. In many cases, color matching is based on stage lighting, but this often results in an unnatural color discrepancy due to the difference in color temperature with the footage on the LED wall.

Panasonic’s new Color Temp. Blend function retains the color temperature data acquired from both the LED wall and stage lighting as reference data, and blends them to generate an optimal white balance for the shooting environment. This enables video expression that accounts for the differences in color temperature across multiple light sources, thereby enhancing visual unity between real subjects and LED wall footage, enabling natural, unobtrusive video production in shooting environments that use LED walls.

Diagram: Color Temp. Blend

2. Target Color Correction Efficiently Adjusts Only the Desired Color

Target Color Correction allows users to designate a specific color and adjust its hue and saturation individually. For example, it enables pinpoint color correction of corporate brand colors or sponsor logos displayed on an LED wall, or specific colors used in a stage production, without affecting the video’s overall color reproduction.

This function can set up to three color tables simultaneously, allowing multiple important colors to be optimized individually. This makes it easier to improve the reproducibility of brand colors and to achieve color expression that matches creative intent, supporting more efficient on-set color matching and higher-quality video production.

Diagram: Target Color Correction

3. Chroma Suppression Naturally Controls Vivid Color Expression

LED displays with vivid CG imagery are commonly used at live events and concert venues. However, extremely saturated colors can cause unnatural color rendering or color saturation in camera footage. The new Chroma Suppression function maintains the overall color reproduction of the video while suppressing color shift and saturation in highly saturated areas, achieving high-quality video expression.

Diagram: Chroma Suppression

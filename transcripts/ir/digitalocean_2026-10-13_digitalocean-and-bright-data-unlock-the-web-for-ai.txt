DigitalOcean and Bright Data Unlock the Web for AI Agents

October 13, 2026

DigitalOcean’s Managed Agents can now act on what is happening across the live open web through a seamless integration with Bright Data's search, access, extract and actioning tools.

BROOMFIELD, Colo.--(BUSINESS WIRE)--

DigitalOcean (NYSE: DOCN) and Bright Data today announced a partnership at The Open Intelligence Summit that brings Bright Data's tools and datasets to DigitalOcean Managed Agents, available now through Action Gateway. Agents on DigitalOcean can now search the live web, access sites that present technical challenges to automated traffic, extract structured data, and act on pre-collected, dynamically refreshed datasets without a separate Bright Data account or API key.

Most agents can search the web, but very few can reliably reach the data businesses depend on. Competitor prices, stock levels, and reviews often sit on sites that automated traffic cannot reliably access. The usual fix is custom code that breaks when sites change, or static datasets that no agent can act on in real time.

A retailer's pricing agent, for example, can read this week's order history, recall that last month's discount on a product category lifted revenue without compressing margin, and access this morning's market prices and product data, before recommending a new price. Each recommendation and its outcome feed DigitalOcean's learning system, so the agent improves with every decision.

"Agents need governed access to a broad set of data to do real work,” said Paddy Srinivasan, CEO, DigitalOcean. “Bright Data brings search and retrieval into the DigitalOcean’s AI-Native Cloud, which handles all the key resources an agent needs, including the runtime, session state, inference, and tool access, so developers can focus on the agent's task instead of its infrastructure."

"We are bringing real-time web data at scale to every team building agents on DigitalOcean, so their agents can act on what is happening across the open web,” said Or Lenchner, CEO, Bright Data. “DigitalOcean's infrastructure is well suited to agents that we plan to build our own on it, giving our customers the shortest path from web data to a running agent."

The partnership will extend in two additional phases. Bright Data's datasets will be integrated into DigitalOcean's Agent Data Services, enabling agents to analyze public web data alongside a customer's own data in a single query. Bright Data also plans to build and deploy its own agents on DigitalOcean Managed Agents, giving customers of both companies a fully managed path from web data access to a running, scalable agent with no infrastructure to manage.

Bright Data tools are available today in the DigitalOcean Managed Agents public preview. To get started, add Bright Data in Action Gateway or visit https://digitalocean.com/products/managed-agents .

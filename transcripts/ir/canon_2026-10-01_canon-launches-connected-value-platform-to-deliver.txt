Canon launches Connected Value Platform to deliver AI-powered feature enhancements for printing products

TOKYO, October 1, 2026—Canon Inc. and Canon Marketing Japan Inc. today announced the launch of Connected Value Platform, a cloud-based feature enhancement platform that combines generative AI and Canon imaging technologies to add new capabilities to a broad range of printing products from home printers to office multifunction devices. As the first phase of this initiative, Canon will offer feature extension tools for PIXUS (PIXMA in other regions), inkjet printers beginning October 1, 2026. 1,2

Overview of Connected Value Platform

As printing needs become more diverse, users increasingly require tools to edit, organize, and reformat documents and images before printing. Traditionally, these tasks have required multiple applications, making workflows more complex and time-consuming.

Connected Value Platform streamlines this process by analyzing documents and images with generative AI and Canon’s imaging technologies, extracting relevant information, reorganizing content, and converting it into formats optimized for print and scan workflows. Users can access these capabilities through feature extension tools within Canon applications for PCs and mobile devices, selecting only the functions they need.

To support the platform, Canon will introduce Canon Print Assistant Ver.2.0 for Windows PCs and Canon PRINT Ver.4.0 for mobile devices. New print and scan capabilities will be delivered as feature extension tools, 3 enabling users to access an expanding range of functions through a single application interface.

The first feature extension tool, Web Print Optimizer, is designed for users who frequently print web content such as recipes and news articles. Using generative AI, it analyzes page content, removes unnecessary elements such as advertisements and excess whitespace, and automatically optimizes layouts for printing. 4

Canon also plans to expand the platform with additional tools, including Content-Based Naming, scheduled for release in late November 2026. 5 This feature uses generative AI to analyze scanned content and automatically generate descriptive file names. Canon will continue adding capabilities for work, learning, hobbies, and everyday life, extending the value of existing printing products through software-based innovation.

Through Connected Value Platform, Canon aims to continuously enhance printing and scanning experiences by delivering new value through cloud connectivity, AI, and imaging technologies.

HPE teams with NVIDIA to bring secure, governed agentic AI into enterprise production

September 28, 2026

Blog Post Hybrid & Private Cloud AI

HPE brings the NVIDIA Open Agent Safety Platform together with infrastructure-level security for private, regulated, and sovereign AI

In this article

NVIDIA Open Agent Safety Platform governs how autonomous agents run, with NVIDIA OpenShell securing the agent runtime and NVIDIA Sentry delivering out-of-band monitoring and policy enforcement on NVIDIA BlueField-4 with NVIDIA DOCA

HPE and NVIDIA extend protection from the agent runtime to the underlying AI infrastructure through the HPE AI Factory with NVIDIA portfolio, inclusive of HPE Private Cloud AI, HPE Sovereign AI factory, and HPE AI factory at-scale

Put Agent controls where they can be enforced

Autonomous AI agents do more than generate answers. They use tools, access data, write files, call APIs, and take actions across enterprise systems.

As their autonomy grows, enterprises need clear answers to three questions:

Where are our agents running? What can they reach? What did they do?

These are operational questions. Controls documented in a policy do not answer them. Controls enforced in the operating environment do.

NVIDIA Open Agent Safety Platform enhances agentic security at enterprise scale across the software that runs agents and the hardware and compute layers that power their work. NVIDIA OpenShell, the secure runtime at the center of the platform, is now generally available. HPE Private Cloud AI is integrating OpenShell to help enterprises apply consistent governance to agent execution, with availability planned for Q4 2026.

Together, HPE and NVIDIA are addressing agent governance at two levels. The runtime governs what an agent can access and change. The underlying infrastructure helps protect data, network traffic, and the systems on which agents operate.

Govern what agents can access and change

OpenShell is open source software that places controls around the environment in which an agent operates. It uses isolated sandboxes and policy enforcement to govern what an agent can read, write, execute, and access over the network, including where inference requests go.

These controls operate outside the agent process. This separates the control boundary from the model, agent harness, or application it governs.

When an agent encounters a policy limit, it can request a change. Operators retain approval authority, allowing permissions to adapt without weakening the established boundary.

The general availability release adds multi-tenancy , Kubernetes-based high availability, extensibility, centralized observability, and policy automation. Enterprises can support different agents, models, and frameworks while applying a consistent runtime boundary across them.

OpenShell is also open source. For infrastructure that governs autonomous systems, transparency matters. Organizations can inspect, test, and improve the trust boundary on which they depend.

Bring governed agent execution to HPE Private Cloud AI

HPE Private Cloud AI is a turnkey AI factory solution as part of the HPE AI Factory with NVIDIA portfolio. HPE is integrating OpenShell into an operating environment designed to connect agent execution with enterprise identity, policy, approvals, observability, and audit.

This approach gives platform and security teams a consistent place to govern agent activity without requiring development teams to use one agent framework. OpenShell supports a variety of models, harnesses, and agents across cloud, hybrid, on-premises , and air-gapped infrastructure.

The objective is straightforward: give agents the access they need to complete approved work without giving them unrestricted access to hosts, networks, credentials, data, or model endpoints. IT Administrators control what the agents can access.

Development teams retain flexibility in how they build agents. IT gains a common boundary for controlling how those agents interact with enterprise resources.

Extend protection beyond the agent runtime

Runtime governance is one part of the architecture. Organizations also need infrastructure-level protection for data, network traffic, workload isolation, and operational evidence.

NVIDIA Sentry is an independent watchdog that monitors agent activity and enforces security policies out of band. It runs on NVIDIA BlueField-4 DPUs and uses NVIDIA DOCA for hardware-isolated monitoring, agent governance, and policy enforcement. NVIDIA DOCA on HPE AI Factory solutions provide software frameworks, libraries, and tools for infrastructure services such as policy enforcement, threat detection, and network protection. HPE plans to support NVIDIA BlueField-4 DPUs across the portfolio of HPE servers, AI rack-scale systems, HPE Private Cloud AI, HPE AI Factory at-scale, and HPE Sovereign AI Factory, with availability based on product lead times.

The NVIDIA OpenShell secure runtime boundary and agentic sandboxes runs on NVIDIA Vera CPU systems, including HPE ProLiant Compute DL394 Gen12, as well as other compute platforms. NVIDIA Sentry runs on BlueField-4 DPUs in a hardware-isolated security domain independent of the host software running those workloads.

HPE is also integrating NVIDIA Confidential Computing with HPE AI Factory solutions through HPE Services. NVIDIA Confidential Computing protects models and private data during execution for on-premises and sovereign deployments. Cryptographic attestation and encryption establish a chain of trust that verifies hardware, software, and datasets. Availability is planned for Q4 2026.

These capabilities can help customers address requirements associated with the Cybersecurity Maturity Model Certification, the National Institute of Standards and Technology 800 series, Security Technical Implementation Guides, and Federal Information Processing Standards. The requirements addressed depend on the configuration and deployment.

Make sovereignty operational

For governments, public sector organizations, and regulated industries, agent governance raises additional questions: Who controls the system? Where does the data reside? Who is authorized to operate the environment?

A model or application cannot answer these questions alone. Organizations must address them across the infrastructure, operating model, and services supporting the AI system.

HPE Sovereign AI Factory extends the HPE AI Factory with NVIDIA portfolio for environments that require greater control over data, infrastructure, operations, and compliance. Combined with a governed agent runtime, this foundation can help organizations operate agents near sensitive data while maintaining defined access and operational boundaries.

Sovereignty is not only about where technology is located. It is about how infrastructure is deployed, controlled, secured, and operated.

Move agentic AI into production with evidence

NVIDIA Open Agent Safety Platform puts agent controls where they can be enforced, and OpenShell provides the governed runtime boundary while Sentry adds out-of-band monitoring and policy enforcement on BlueField-4. The HPE AI Factory with NVIDIA portfolio is integrating that boundary and connecting it to infrastructure designed for private, regulated, and sovereign operation.

This approach extends governance from the actions an agent takes to the infrastructure supporting those actions. It gives enterprises a clearer way to define access, enforce policy, observe activity, and maintain an auditable record.

Agentic AI is ready for production when an organization can show where its agents run, what they can reach, and what they did.

The next step is to make those answers enforceable, observable, and auditable.

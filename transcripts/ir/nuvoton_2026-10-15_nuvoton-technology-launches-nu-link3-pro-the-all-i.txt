Nuvoton Technology Launches Nu-Link3-Pro : The All-in-One Multifunctional Tool for Embedded Developers

Logic Analysis, High-Performance Computing Core, Flexible Automated Programming, and Advanced Communication Protocol

Hsinchu, Taiwan – October 15 , 2026 – Nuvoton Technology Corporation, a leading global semiconductor provider, proudly introduces the Nu-Link3-Pro , a groundbreaking programmer and debugger specifically designed for embedded system developers. Nu-Link3-Pro is not only the world's first programming debug analyzer that integrates logic analysis functionality, but its powerful multi-protocol support and automated programming capabilities also deliver unparalleled development efficiency for product developers.

The core technology architecture of the Nu-Link3-Pro is based on USB Type-C Interface, significantly enhancing connection stability. For the NuMicro ® series microcontrollers, its ETM real-time instruction trace frequency is boosted to 110 MHz, allowing developers to capture system behavior more accurately in high-frequency applications, thereby greatly optimizing real-time system debugging efficiency. Additionally, the Nu-Link3-Pro supports multiple voltage ranges, including 1.8V, 2.5V, 3.3V, and 5.0V, catering to various Hardware requirements.

The standout feature of the Nu-Link3-Pro is its built-in logic analysis function, enabling developers to perform digital signal capture and multi-protocol decoding without additional Hardware. This innovative design allows debugging, programming, and signal verification to be completed on a single platform, significantly reducing Hardware verification and debugging time.

In terms of programming capabilities, the Nu-Link3-Pro supports MicroPython, allowing developers to achieve fully customized automated offline programming logic by simply storing a custom MAIN.PY script on a Micro SD card. This flexibility adapts to different automated testing platforms or mass production environments, making the Nu-Link3-Pro a powerful tool for USB to multi-protocol bridging, offering diverse application scenarios and significant advantages.

For peripheral Interfaces, the Nu-Link3-Pro supports traditional SPI, I²C, UART, and RS-485 Interfaces, with added support for I3C and CAN FD Interfaces, meeting the big data frame development needs of automotive and industrial applications. These rich peripheral options make the Nu-Link3-Pro an essential tool for developers tackling complex embedded systems.

Additionally, as product security awareness continues to grow, Nu-Link3-Pro also offers a value-added Secure Provisioning service. The private key is generated within Nu-Link3-Pro and securely stored in a hardware Key Store, with a hardware encryption/decryption engine handling certificate issuance and encrypted programming to ensure the private key never leaves the device. These capabilities can be customized according to the target chip and application requirements, and Nuvoton can provide project assessment and technical support.

For more details on the Nu-Link3-Pro, please see: https://www.nuvoton.com/tool-and-software/debugger-and-programmer/1-to-1-debugger-and-programmer/nu-link3-pro/index.html?index=0&_t=20668

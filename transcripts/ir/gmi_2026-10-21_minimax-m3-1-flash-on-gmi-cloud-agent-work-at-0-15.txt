October 21, 2026

Why cost per task is the number that matters now

An agent run is hundreds of model calls, each one reading the growing context and writing the next step. Per-token price times tokens consumed is the bill, and a model that reasons in fewer tokens wins twice.

MiniMax released M3.1 Flash on October 19, 2026. It is the model that ran anonymously as "Space Bunny" and processed over 200 trillion tokens before the reveal. MiniMax reports agent task costs 70% lower than M3, with output peaking above 200 tokens per second and a median above 170. Artificial Analysis measured about $0.22 per task on its Intelligence Index, down from $0.51 for M3, while the index score rose from 29 to 42.

The model is available today on GMI Cloud as MiniMaxAI/MiniMax-M3.1-Flash , served in FP8 with the full 1,048,576-token context.

Demo: a shinto shrine for $4.50

We pointed a coding agent at M3.1 Flash on GMI Cloud and asked for a shinto shrine as a 3D web scene. Four hours of autonomous agent work, including planning, writing the scene code, iterating on lighting and layout, and fixing its own runtime errors, cost $4.50 in tokens.

Hands-on: five tasks through the GMI endpoint

Benchmarks tell you where a model ranks. A hands-on run tells you what it feels like to build with. We gave M3.1 Flash a small tool-calling loop (three tools: run_shell , write_file , read_file ) against the GMI Cloud OpenAI-compatible endpoint and five tasks in an empty folder on a Mac. Test assets came from other GMI Cloud models: gemini-3-pro-image drew a shrine signboard reading "OPEN 9 TO 5" and MiniMaxAI/MiniMax-M2.7 wrote a two-page maintenance PDF with six part numbers.

Two things stood out.

It reads a whole project at once. We handed it the full shrine codebase (about 103,000 tokens) in a single request and asked three questions about it. It answered in 21 seconds, and every file and line number it cited was correct.

It builds more than you ask for. The brief was a gate, six lanterns, a pond and a bridge. It added animated water, a dusk sky, fireflies and a shrine hall on its own, and the camera drifts around the scene at a steady pace and pauses when you grab it.

The flip side is that it keeps working after the job is done. It took 23 steps to count three files, and once the shrine was written it wanted to open a browser and look at it. Give it a clear finish line and a step limit, and it behaves.

The speed gain comes from MiniMax Sparse Attention (MSA) plus a small active-parameter count: the model reads less of the context on each step and moves less data through GPU memory, which is where throughput is decided on H100 and B200 class GPUs.

Where to be careful

The agent scores above come from MiniMax's own model card. Artificial Analysis has published independent numbers for the Intelligence Index, Humanity's Last Exam, and factuality, and those are the ones to lean on until third parties rerun the agent suites.

Factuality is the weak spot. On AA-Omniscience, M3.1 Flash answers 56% of questions correctly, ahead of DeepSeek V4.1 Flash at 43% and GLM-5.3 Flash at 28%. When it lacks the answer, though, it guesses: a 93% hallucination rate: when it misses, it almost always gives a confident wrong answer instead of saying it is unsure.

For agent work this is manageable. Pair the model with retrieval, tool results, and verification steps so facts come from the environment rather than from the weights. For open-ended Q&A with zero grounding, pick a different model.

Two small discrepancies in the published material: MiniMax's cost chart shows Automation-Bench at 62.8 while its table shows 62.2, and DeepSeek V4.1 Flash on DeepSWE appears as both 74.2 and 77.0 across sources. This post uses the table values.

Quickstart on GMI Cloud

The endpoint is OpenAI-compatible, so anything that takes a base URL and a model ID works. Try it in the playground or grab a key from the GMI Cloud console .

curl https://api.gmi-serving.com/v1/chat/completions \

-H "Authorization: Bearer $GMI_API_KEY" \

-H "Content-Type: application/json" \

-d '{"model": "MiniMaxAI/MiniMax-M3.1-Flash", "messages": [{"role": "user", "content": "Plan a Three.js scene of a shinto shrine at dusk."}]}' Point Claude Code, OpenCode or Cline at the same base URL and model ID and you have a coding agent. Stream long replies, and keep the system prompt stable across turns so the $0.015 cached-input rate covers most of each request.

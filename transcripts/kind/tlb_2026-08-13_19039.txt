6
Server Memory Module
여러 개 D램이 결합된 모듈 제품으로,
랭크(Rank) 2개 동시 작동으로 속도 향상
MR-DIMM(Multiplexed Rank DIMM)
• AI 데이터 센터와 같이 거대한 서버에 들어가는
메모리로, 안정성과 신뢰성이 높아 고부하 작업에 필수
• 단순한 저장공간이 아닌 무수히 많은 데이터를
처리하고 AI 연산에 필요한 정보를 정리
DDR5 6400/7200 MT/s
DDR5 8000  MT/s
R-DIMM
MR-DIMM은 데이터 버퍼를 이용해 랭크 2개를 동시에 작동시켜
대역폭을 R-DIMM 대비 두 배로 확장한 메모리로 기존 서버용 D램
대비 동작 속도는 80% 이상 향상되고, 높은 폼팩터를 적용한 제품
디지털, 아날로그, 혼합 신호 회로를 하나의 칩에 집적해
소형 고성능 저전력을 구현한 제품
SOCAMM
(Small Outline Compression Attached Memory Module)
지정된 CPU에 메모리 제공할 뿐만 아니라,
지정되지 않은 CPU에 메모리 확장한 제품
CXL(Compute Express Link)
SSD
Next Gen. Modular Memory
LPDDR 기반의 새로운 폼팩터로
전력을 최소화하여 열발생을 줄이는데 주로 사용
LPCAMM
(Low Power Compression Attached Memory Module)
e-SSD
(Enterprise SSD)
EDSFF
(Enterprise & Datacenter SSD Form Factor)
